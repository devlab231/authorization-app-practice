# authorization-app-practice

## 概要
COACHTECH 教材 Tutorial 10-3「認可機能 ハンズオン演習」で作成した成果物です。<br>
LaravelのPolicyを使用して、投稿の編集・削除権限を制御するWebアプリケーションを作成しました。

## 使用技術
- PHP 8.5.12
- Laravel 10.50.3
- Policy / Gate（認可）
- Laravel Fortify（認証）

## 学んだこと
- Policyを使用して、ログインユーザーと投稿の作成者を比較し、編集・削除の権限を判定する方法
- authorize()を使用して、権限のないユーザーによる操作を403 Forbiddenエラーで拒否する方法
- Bladeの@canディレクティブを使用して、ユーザーの権限に応じて編集・削除ボタンの表示を制御する方法

## 動作確認
GitHubから本プロジェクトを取得し、Laravel Sailを使用して起動することで動作確認できます。<br>
ユーザーA・Bでそれぞれログインし、自分の投稿のみ編集・削除できること、他人の投稿には操作ボタンが表示されず、<br>
URLへの直接アクセスや不正な更新・削除操作が403エラーで拒否されることを確認してください。<br>
※ 実行にはDocker環境および初期設定が必要です。
